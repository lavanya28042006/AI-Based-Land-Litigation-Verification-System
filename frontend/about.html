1. About the Project / திட்டத்தைப் பற்றி

LandVerify is an academic demonstration project that allows users to search available land records using details such as district, village and survey number.

LandVerify என்பது கல்வி நோக்கத்திற்காக உருவாக்கப்பட்ட செயல்முறை விளக்கத் திட்டமாகும். மாவட்டம், கிராமம் மற்றும் சர்வே எண் போன்ற விவரங்களைப் பயன்படுத்தி கிடைக்கக்கூடிய நிலப் பதிவுகளைத் தேட இது உதவுகிறது.

2. Project Objectives / திட்டத்தின் நோக்கங்கள்

  • Easy Land Search: Provide a simple interface to search land records.

    எளிய நிலத் தேடல்: நிலப் பதிவுகளை எளிதாகத் தேடுவதற்கான வசதியை வழங்குதல்.

  • Case Information: Display available land and case-related information.

    வழக்கு விவரங்கள்: கிடைக்கக்கூடிய நிலம் மற்றும் வழக்கு தொடர்பான தகவல்களைக் காட்டுதல்.

  • Search History: Save and review searches associated with the logged-in account.

    தேடல் வரலாறு: உள்நுழைந்த பயனரின் தேடல்களைச் சேமித்து மீண்டும் பார்வையிடுதல்.

  • PDF Report: Download a report of the displayed search result.

    PDF அறிக்கை: திரையில் காட்டப்படும் தேடல் முடிவின் அறிக்கையைப் பதிவிறக்கம் செய்தல்.

  • AI Assistance: Provide an AI-assisted explanation based on submitted information.

    AI உதவி: வழங்கப்பட்ட தகவல்களின் அடிப்படையில் AI மூலம் விளக்கத்தைப் பெறுதல்.

3. Key Features / முக்கிய அம்சங்கள்

Land Search / நிலத் தேடல்

Search available land records using location and survey details.

இட விவரங்கள் மற்றும் சர்வே எண்ணைப் பயன்படுத்தி கிடைக்கக்கூடிய நிலப் பதிவுகளைத் தேடலாம்.

User Dashboard / பயனர் முகப்புப் பலகை

View search statistics and recent search activity.

தேடல்களின் எண்ணிக்கை மற்றும் சமீபத்திய தேடல் விவரங்களைப் பார்க்கலாம்.

Search History / தேடல் வரலாறு

Review previous searches saved for your account.

உங்கள் கணக்கில் சேமிக்கப்பட்ட முந்தைய தேடல்களைப் பார்வையிடலாம்.

PDF Report / PDF அறிக்கை

Download a report containing the displayed land details.

திரையில் காட்டப்படும் நில விவரங்களைக் கொண்ட அறிக்கையைப் பதிவிறக்கம் செய்யலாம்.

AI Assistance / AI உதவி

Obtain an AI-generated explanation based on submitted data.

வழங்கப்பட்ட தரவுகளின் அடிப்படையில் AI உருவாக்கும் விளக்கத்தைப் பெறலாம்.

Role-Based Access / பயனர் பங்கு அடிப்படையிலான அணுகல்

Restrict protected administrative actions according to user role.

பயனர் பங்கின் அடிப்படையில் நிர்வாகச் செயல்களுக்கான அணுகலைக் கட்டுப்படுத்தலாம்.

4. Technology Stack / பயன்படுத்தப்பட்ட தொழில்நுட்பங்கள்

  • Frontend: HTML, CSS, Vanilla JavaScript

    பயனர் இடைமுகம் உருவாக்கப் பயன்படும் தொழில்நுட்பங்கள்.

  • Backend: Node.js and Express.js

    சர்வர் மற்றும் API செயல்பாடுகளுக்குப் பயன்படும் தொழில்நுட்பங்கள்.

  • Database: MySQL

    நிலப் பதிவுகள், பயனர் விவரங்கள் மற்றும் தேடல் வரலாற்றைச் சேமிக்கிறது.

  • Authentication: JSON Web Token (JWT)

    உள்நுழைவு அடிப்படையிலான API அணுகலைக் கட்டுப்படுத்த உதவுகிறது.

  • AI Integration: OpenRouter API

    வழங்கப்பட்ட தகவல்களுக்கு AI மூலம் விளக்கம் பெறப் பயன்படுகிறது.

5. Important Disclaimer / முக்கிய அறிவிப்பு

This is an academic demonstration project. The sample data and AI-generated responses are not official government records or legal advice. A search result alone cannot prove that a property is free from litigation. Please verify property details using appropriate official records and qualified professionals.

இது கல்வி நோக்கத்திற்காக உருவாக்கப்பட்ட செயல்முறை விளக்கத் திட்டமாகும். இதில் உள்ள மாதிரித் தரவுகளும் AI உருவாக்கும் பதில்களும் அதிகாரப்பூர்வ அரசு பதிவுகளோ சட்ட ஆலோசனையோ அல்ல. தேடல் முடிவு மட்டும் ஒரு நிலத்தில் வழக்கு இல்லை என்பதை உறுதிப்படுத்தாது. சம்பந்தப்பட்ட அதிகாரப்பூர்வ பதிவுகள் மற்றும் தகுதியான நிபுணர்கள் மூலம் நில விவரங்களைச் சரிபார்க்கவும்.
